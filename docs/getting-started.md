# 0.1.1 新版使用指南

枕星图吧AI助手帮助你把目标拆成可执行的工具使用路径。第一次使用，先完成客户端启动和 AI 配置，再从一个具体目标开始。

[官网下载 Windows x64 便携包](https://zhenxingai.com/download) · [GitHub 备用下载](https://github.com/yujinchuan2021-max/zhenxing-ai-assistant/releases/tag/v0.1.1-preview) · [常见问题](faq.md) · [批量更新修订说明](releases/0.1.1-batch-update-20261007.md) · [回到项目首页](../README.md)

## 1. 启动客户端

关闭正在运行的旧客户端，将完整 ZIP 解压到新文件夹，运行根目录 **`枕星图吧AI助手.exe`**。请保留解压后的目录结构，随包资源与运行时需要一起使用。

这是 Windows x64 便携版。部分系统和硬件功能需要管理员权限，按 Windows 提示操作。公开源码、便携包和历史 Electron 安装包的用途不同，请从 0.1.1 发布页取得当前客户端。

## 2. 配置 AI 与 Agent

打开 **“设置 → AI 与 Agent”**，选择或填写模型服务地址、模型和凭据，并测试连接。客户端内的对话、技能制作、个人资讯整理等功能共用这份配置；切换服务或模型后，后续请求使用相应配置。

已有订阅、API 或本地模型服务，可以先确认能否兼容当前接入。订阅会员与 API 额度由服务商分别提供，不能仅凭已有聊天会员就判断第三方 Agent 能直接使用。

外部 Agent 是你在后续制作或开发中使用的独立软件。它需要自己的可用账号或兼容接入；枕星客户端的全局配置不会自动登录它，也不会把随包内部运行时当成已经安装好的外部开发工具。

还没配置模型时，你可以先查看应用中心、使用本机电脑工具、浏览公开技能目录和服务器资讯。依赖模型的功能会提示先接通 AI 服务。

## 3. 描述目标并选择方案

目标最好包含期望结果和运行环境，例如：

- “我想在 Windows 上开发一款 2D 游戏。”
- “我只需要用 AI 生成一首背景音乐并下载。”
- “这台电脑最近很卡，先帮我找原因。”

助手只追问会改变当前选择的关键条件。有明确答案范围时，直接点击选项；也可以自由补充。已经说明的目标、预算、账号和本机环境会继续作为方案约束。

需要选择模型投入时，提供四个选项：

1. 可以付费，并使用顶级模型。
2. 可以付费，需要便宜的模型。
3. 不想付费，用本地模型。
4. 我也不知道，给我推荐。

本地模型先核对硬件。开发路线会比较 Agent、模型接入与必要开发环境；桌面版优先，CLI 仅在符合用户选择或任务条件时使用。直接生成音乐等目标按所需服务处理，不默认额外配置编曲、混音或编程工具。

## 4. 确认准备清单

选择方案后，核对需要准备的软件和服务，再确认开始。客户端会对支持的项目执行下载、安装、检测和入口准备，按真实结果更新工作台。

符合当前任务要求的本机软件优先复用。安装目标会区分桌面版、命令行版和地区版本；同名 CLI 不等于已安装桌面版，国内下载镜像也不等于国内版软件。

账号注册、登录、订阅、地区资格或不支持自动处理的项目需要本人操作，工作台会显示对应步骤。一次确认覆盖已核对的准备范围，不代表所有第三方登录和付款都能自动完成。

## 5. 从入口继续使用

完成准备后，查看“就绪工具与打开方式”：

- **桌面软件**：通过“打开软件”启动，支持且入口验证成功时尝试创建桌面快捷方式；可查看“打开位置”。
- **CLI**：按卡片说明打开 PowerShell，在项目文件夹中使用提供的启动命令；首次启动可能仍需登录或配置模型。
- **账号或服务**：完成当前确实必要的注册、登录或配置步骤，再回到工作台核对。

“已安装”“已创建入口”“账号已连接”“实际使用已验证”是不同结果。打开工具后，按照下一步说明在选定软件里继续制作或开发；环境准备完成不会被当成作品已经交付。

## 6. 管理软件、技能与内容

**应用中心**用于查看本机检测结果、应用管理记录和下载任务。存在记录但未找到入口时，先刷新或重新检测。“移除记录”只移除登记；“卸载”才调用对应的卸载方式。

**性能测试与排行榜**可运行测试、查看或导出报告，再主动选择是否向枕星服务投稿。投稿先进入审核，采纳后公开报告信息及匿名投稿名；本机“我的记录”可查看和撤回投稿。审核采纳不等于成绩已经独立验证。

**官方技能库**提供分类、搜索和技能详情。瀑布流先预加载前两页，向下滚动继续读取，筛选和搜索会读取目录索引；当前显示数量不等于全库只有这些技能。查看来源和许可后，按详情页提供的加载方式使用。

**修改技能**允许编辑内置目标技能并在本机试用；**制作技能**使用你配置的 AI，根据用途和简短选项生成文本技能草稿。生成后可修改、保存并加载，再按投稿页面确认分享许可并主动提交审核。本机试用成功与服务器审核通过是两个状态。

**枕星AI资讯**提供自建服务更新的公开内容，默认每天北京时间 **09:00** 自动更新，无需让客户端或 Codex 常开。未配置个人 AI 也可读来源资讯与原文；个人 AI 摘要和精选使用客户端配置的模型，按该服务计费。

**枕星AI社区**用于分享目标、工具流、经验和问题。普通浏览在内置浏览器继续；当前版沿用 r10 的修复，让受支持的官方身份授权留在同一会话，特殊方式会提示从浏览器重新登录。社区账号与模型服务账号独立，浏览器登录也不会自动登录客户端。

## 升级与反馈

官网下载页与 GitHub 发行页提供当前修订包及对应 SHA-256，核对相同文件名与校验值后使用。公开名称为 0.1.1，本次程序内部修订为 0.1.1.2；此前 0.1.1.0、0.1.1.1 和 0.1.0 客户端可通过更新清单检测新版提示。检测到更新并不代表已完成升级：下载、校验后，仍需自行关闭旧版、完整解压到新文件夹并启动新版。当前流程不会自动替换、解压或重启程序。

安装新版后，应用中心的「全部更新」显示本机受管便携工具的可更新数量。确认工具清单和下载大小后，客户端下载并逐项应用；离开页面仍会继续。正在运行的工具等待关闭，失败项保留原版本；任务卡可查看原因或取消本批剩余更新。本地登记的软件、原厂安装器、商店应用、账号登录和启动 U 盘按各自流程处理。

1. 升级前，在设置中确认实际配置保存位置，导出配置，并备份需要保留的数据目录。单独保留自行添加的工具和第三方 Agent 配置；客户端配置导出不能保证包含这些外部内容。
2. 关闭旧客户端，将完整 ZIP 解压到新文件夹，保留旧文件夹供回退。不要覆盖仍在运行的程序，也不要只复制 EXE。
3. 默认数据目录为 `%LOCALAPPDATA%\TubaWinUi3`，同一 Windows 用户启动新版时继续读取原位置。会话、模型配置等应保留整个数据目录，不能只保留一个设置文件。
4. 如果选择了应用目录保存，保留旧客户端实际程序目录下的 `Data` 及其中的 `.config_location` 标记，放到新客户端相同位置；便携包中通常是 `src\Data`。如果使用自定义目录，保留位置标记并确认它仍指向原数据目录；相对路径还需保留对应目录结构。确认新版能看到原设置和会话后，再处理旧程序文件夹。

历史 Electron 版本使用另一套更新和数据结构，不能把它的配置文件直接替换进 WinUI 3 数据目录，也不能承诺会话自动迁移。安装 0.1.1 后重新配置模型服务，保留旧版数据供查阅。密钥与 Windows 用户绑定，复制到其他用户或电脑不等于可以继续解密使用。

当前版本为预览版。真实社区账号注册、登录还需要实际复测，原生测试宿主退出异常仍在记录中。遇到问题请向 [社区](https://community.zhenxingai.com/) 或 [GitHub Issues](https://github.com/yujinchuan2021-max/zhenxing-ai-assistant/issues) 提供版本、系统、最后一步操作和脱敏截图。
