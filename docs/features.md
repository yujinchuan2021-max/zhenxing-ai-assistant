# 功能总览

[返回项目首页](../README.md) · [快速开始](getting-started.md) · [官网功能总览](https://zhenxingai.com/features) · [常见问题](faq.md)

本页按用户任务梳理枕星图吧AI助手 **0.1.1 公开预览版**的入口、动作和使用条件。工具目录会更新，具体项目、获取方式与可用状态以客户端和官方目录为准。源码审计与尚未发布的研究内容不作为公开包已经具备的能力。

## AI 任务工作台

**用途：** 从“我想完成什么”开始，选择合适工具并准备下一步。

- 在首页描述目标，回答影响平台、预算、账号、网络或硬件选择的关键问题。
- 比较方案，确认准备清单，优先复用符合条件的本机软件。
- 查看当前步骤、执行回执、就绪工具和打开方式，继续调整方案或排查问题。
- 开发与创作类任务在所选 Agent、引擎或生成服务中继续；工具准备与最终成果分别呈现。

**使用条件：** 对话需要可用的 AI 配置。外部 Agent 的登录与模型接入按该产品要求完成。

## 模型与 Agent 配置

**用途：** 为客户端的 AI 功能设置模型连接，并按目标选择外部 Agent。

- 在“设置 → AI 与 Agent”配置服务地址、模型、凭据和可用的兼容服务。
- 结合预算、账户、网络、平台和硬件条件选择桌面软件、CLI 或本地方案。
- 支持的桌面入口提供打开方式；CLI 提供终端说明与启动命令。

**使用条件：** 客户端的模型配置不会自动登录第三方软件。模型费用、订阅与地区访问要求由提供方决定；本地服务需匹配模型及硬件能力。

## 应用中心

**用途：** 管理已经取得的软件与下载任务，找到下一次使用的入口。

- 查看本机检测结果、登记的软件和下载任务，按名称和状态查找。
- 使用打开软件、打开位置、创建支持的桌面快捷方式等操作。
- 确认清单后“全部更新”已安装的受管便携工具，查看每项进度、失败或等待状态。
- 区分“移除记录”和实际“卸载”；无入口的记录不会被当作可直接打开的软件。

**使用条件：** 正在使用的工具可能需要先关闭。外部安装的软件采用自身更新与卸载流程；取消等待或启动安装器不等于更新、安装已经成功。

## 工具目录与下载

**用途：** 按用途找到诊断、维护或开发工具，再按实际获取方式使用。

- 内置系统功能由客户端提供；受管第三方便携工具按需下载、校验后使用。
- 查看对应版本、架构、来源和软件的实际入口。
- 安装器、商店、网页服务和启动介质分别给出适用流程。
- 收藏常用工具，使用搜索、分类与支持的快捷入口。

**使用条件：** 自有服务器分发范围不等于全部目录条目。某些工具仍需原厂页面、账号、商店许可或特殊操作；工具及依赖的网络条件分别判断。

## 硬件信息与验机

**用途：** 了解设备配置，选择进一步检查或测试的项目。

- 汇总处理器、主板、显卡、内存、显示器、磁盘、系统及相关设备信息。
- 使用快速验机、屏幕检测、键盘检测、电池分析、磁盘健康等入口。
- 通过专用硬件工具核对具体设备参数和实际现象。

**使用条件：** 不同设备和驱动能提供的数据不同；部分检测工具需要权限或另行下载。检测结果是进一步排查的依据，单次检查不代表所有硬件状态均已验证。

## 性能测试与记录

**用途：** 查看性能测试结果，保留报告并按需要分享。

- 从性能测试、压力测试和监控入口选择对应项目。
- 查看或导出测试报告；查看 CPU、GPU 等公开成绩及游戏监控记录。
- 用户主动确认跑分投稿，审核后的成绩进入枕星公开服务。

**使用条件：** 测试结果与硬件、驱动、负载和测试方法有关。审核采纳不等于对测量结果进行了独立验证；展示配置不改变实际测试性能。

## 配置修改器

**用途：** 编辑本机展示名称，保留原始状态并查看应用结果。

- 编辑 CPU、主板、显卡、内存、显示器和硬盘六类展示名称。
- 选择具体设备，搜索公开版中的 96 个型号或自定义输入。
- 本地展示配置与系统同步分别呈现；支持的同步项包括 CPU/主板显示字符串和所选设备的 PnP `FriendlyName`。
- 修改前保存原始状态，逐项显示应用与恢复结果，失败项保留备份供处理。

**使用条件：** 内存名称只保存本地展示配置。修改展示字符串不会改变真实硬件，第三方软件仍可能读取真实信息。系统同步需要相应权限。

[主客户端修订说明](releases/0.1.1-revision-20261006.md) · [独立项目源码](https://github.com/yujinchuan2021-max/zhenxing-hardware-editor)

## 技能库、编辑与投稿

**用途：** 找到可复用的工作方法，并按自己的需要制作或调整技能。

- 在官方技能库分类浏览、全库搜索，查看说明、来源和使用条件。
- 瀑布流预加载前两页，继续滚动加载更多；已显示数量与目录总量分开。
- 从文件或 Git 导入支持的技能；在本机编辑、制作、保存和试用。
- 主动投稿到服务器审核流程；本地试用、审核和上架分别显示。

**使用条件：** 技能可能要求特定工具、模型或权限，加载前查看来源与内容。AI 制作需要模型配置。来源热度、已加载或审核通过不表示所有环境的效果已经验收。

## 系统、文件与磁盘

**用途：** 选择对应的系统维护和文件处理工具。

- 系统维护：启动项、服务、Windows 功能、时间同步、右键菜单和运行库修复等入口。
- 文件与磁盘：磁盘健康、空间查看、垃圾清理、局域网文件分享等入口。
- 格式转换：按页面支持的格式处理图片、文档或音视频，部分处理依赖外部工具。
- 外部维护软件显示自己的下载或安装方式，原厂软件保留来源。

**使用条件：** 这些是不同操作，按页面显示的权限、预览或确认执行；涉及文件、服务和系统设置时，先确认目标与内容。局域网文件分享为 HTTP 服务，在可信局域网开启，用完停止；具体转换格式及所需组件以工具页面为准，旧 Office 格式需要本机 Office / WPS。

## 网络与游戏辅助

**用途：** 查看网络现象、检查连接和使用游戏辅助工具。

- 网络入口包括端口查看、Hosts、网速测试、代理、流量监控和网络设置等。
- 游戏入口包括监控悬浮层、记录、辅助显示和虚拟局域网工具等。
- 针对具体问题选择相应检查，使用记录继续排查。

**使用条件：** 某些功能需要管理员权限、依赖安装或外部服务连接。虚拟局域网和网络设置的实际效果取决于设备、网络与所选工具；不保证所有游戏或网络环境均适用。

## AI 资讯与社区

**用途：** 阅读有来源的信息，交流工具使用和问题。

- 枕星AI资讯提供官方更新、来源与原文入口；服务默认每天北京时间 09:00 更新，失败时保留有效缓存。
- 客户端可按个人模型配置做额外摘要或精选，公开资讯无需配置个人模型。
- 社区交流目标与工具流、使用经验、教程和反馈；可从官网或客户端进入。
- 软件缺陷可提交 GitHub Issue，不适合公开的信息按安全反馈渠道处理。

**使用条件：** 社区账号独立，部分登录方式需要外部浏览器。真实注册与登录仍有自己的验收范围，不以隔离测试替代实际账号流程。

## 设置、数据与隐私

**用途：** 管理外观、模型连接和分享选择。

- 支持浅色、深色和跟随系统，提供界面语言与导航等设置。
- 根据使用方式保留数据目录；升级时先关闭旧版，完整解压新版并核对数据位置。
- API Key 通过 Windows 当前用户的数据保护机制保存在本机，模型请求发送到你配置的服务。
- **工具流分享默认开启**，可能包含目标、完整方案、该会话完整可见对话与执行结果。可在设置关闭；关闭后停止新的上传，关闭期间记录不补传，已上传内容不会自动删除。技能和跑分投稿另需主动提交。

## 当前版本与开发进展

公开包为 **0.1.1 / 内部版本 0.1.1.2**，当前维护文件带 `20261007-fix3`。更新客户端下载后仍需完整解压与重启；应用中心批量更新只覆盖已安装的受管便携工具。
