# V0.1 · r10 常见问题

[下载新版](https://github.com/yujinchuan2021-max/zhenxing-ai-assistant/releases/tag/v0.1.0-preview-r10) · [使用指南](getting-started.md) · [更新与已知限制](releases/r10.md) · [项目首页](../README.md)

## 当前版本有代码签名或第三方认证吗？

r10 包内本项目的启动器、主客户端和后端程序尚未提供数字签名。发布页提供 SHA-256 和对应标签源码，便于核对文件与追溯版本；文件校验不能替代发布者签名或安全评审。上游项目取得的签名、评审和收录属于上游，本项目不会将其作为自己的认证展示。今后取得独立签名或第三方认可后，会公布对应机构、验证入口及适用版本。

## 枕星主要帮我完成哪一步？

从目标出发，帮助选择方案、复用已有环境、准备工具并说明下一步。需要开发游戏、APP 或网站时，后续开发在选定的软件或外部 Agent 里继续；需要 AI 生成音乐等结果时，按对应生成服务处理。安装与环境准备成功不代表作品已经完成。

## 没有 API Key 能用吗？

可以使用本机电脑工具、查看应用中心、浏览公开技能目录和服务器资讯。AI 对话、技能制作和个人资讯整理需要可用的模型配置。已有兼容本地服务时可按 AI 设置页接入，但模型运行所需的硬件、资源和服务启动仍需准备。

## “一次配置全局通用”包括第三方 Agent 吗？

指客户端内的 AI 功能共用“AI 与 Agent”配置。外部 Agent 是独立软件，其登录、模型兼容、订阅和 API 额度由该产品决定，不会因为枕星接通了模型就自动登录外部软件。

## 为什么有时仍需要回答问题？

只有会改变可行方案的条件，例如目标平台、预算、账号或关键网络条件，需要继续确认。已经提供的条件应继续沿用；有明确答案范围时点击选项即可，也可以自由补充。“不确定，帮我推荐”是有效答案，不等于同意购买或安装额外软件。

## 为什么方案不会总是推荐某一个模型或 Agent？

选择需要同时满足目标能力、实际接入、预算、地区、网络和硬件。推荐应以当时可核对的信息为准，客户端没有把品牌或旧型号固定成永久“最强”。桌面版、CLI、国内版和国际版的账号与能力也分别核对。

## 点击确认准备，能直接把所有事情做完吗？

支持自动处理的项目会在核对范围内继续下载、安装、检测和提供入口。第三方注册、登录、订阅、权限窗口及不支持的安装方式仍可能需要本人完成。软件安装、启动入口和真实使用验证分别记录，失败或未验证的步骤会保留实际状态。

## 已经安装的软件还要重新安装吗？

符合当前任务身份、版本和能力要求的软件应优先复用。已有记录或同名软件只是线索，还需要检测真实入口；CLI 不会冒充桌面版。无法确认的项目保留待核对状态，不把登记记录直接当成已安装成功。

## 软件装好了，在哪里打开？

从任务工作台的“就绪工具与打开方式”或应用中心打开。支持的桌面软件在入口验证成功后尝试创建桌面快捷方式；快捷方式失败可以重试。CLI 卡片提供终端打开方式和启动命令。入口暂未找到时刷新或重新检测，不要仅凭安装记录判断软件一定可用。

## 应用中心的“移除记录”和“卸载”有什么区别？

“移除记录”只删除应用登记，不卸载软件、不删除安装文件。“卸载”才调用支持的卸载方式。提示未找到安装包或入口时，可能是历史记录与本机状态不同，应先刷新核对，卸载失败不会被当成成功。

## 技能库为什么只看到一部分？

技能卡片采用瀑布流，先预加载前两页，滚动继续读取，避免一次创建全部卡片。页面当前显示的数量与服务器目录总量不同。分类、搜索会继续读取索引；具体技能数量以实时目录为准，不写固定营销数字。

## GitHub 星数高的技能就一定有效吗？

星数用于了解项目关注度，不能代替当前客户端兼容性和实测。查看技能的用途、来源、许可及加载条件；技能是提供给模型的指导，不会凭空增加客户端权限、工具或网站访问能力。

## 修改或制作的技能会立即上传吗？

不会。编辑结果可以先在本机试用；制作草稿点击“保存并加载”后才写入本机。主动点击投稿并确认分享许可后，服务器才接收该份内容。本机试用与后台审核分别显示，待审或退回不等于公开上架。

## 官方资讯一定要我配置 AI 才有吗？

不需要。自建资讯服务提供来源更新和原文，默认每天北京时间 **09:00** 自动更新；失败时保留有效缓存。客户端的个人 AI 摘要和精选使用你配置的模型，相关请求与费用由该服务决定。官方服务与个人模型配置相互独立。

## 跑分会自动上传或立即进入排行榜吗？

不会自动上传。确认投稿后，客户端向枕星服务发送所选报告的硬件信息、成绩、测试条件及选择附带的热力图；与工具流分享开关分开。新投稿先待审核，采纳后公开报告和匿名投稿名；本机“我的记录”可以查看与撤回。采纳不代表成绩已独立验证，细节见 [隐私说明](../PrivacyPolicy.txt)。

## 社区注册或登录仍提示授权超时怎么办？

先确认运行的是 r10，从社区首页重新点击注册或登录，不继续旧版已经打开的授权链接。受支持的官方身份授权在同一个内置浏览器里继续；如果出现“在浏览器重新登录”，从该入口重新开始。浏览器登录只在该浏览器生效，不会自动将客户端登录。

真实账号注册和登录尚未完成本版实际验收。如仍失败，请提供脱敏截图、最后一次操作、版本和系统信息；不要把包含授权码或状态参数的完整链接公开到论坛或 Issues。

## 这是正式稳定版吗？

当前是 **V0.1 · r10 公开预览版**。207 项社区相关逻辑测试、2 项原生隔离授权功能用例与 8 项离线检查已通过。原生宿主退出仍出现微信输入法模块异常，真实账号注册与登录未验证；这些结果不会被合并成“全部场景已通过”。见 [验证说明](releases/r10.md)。

## 我以前下载的 0.1.100 和现在 r10 是同一套客户端吗？

仓库旧标签中的 Electron 实现属于历史版本。当前默认分支和 r10 包提供 WinUI 3 / .NET 10 实现。旧历史保留供追溯，旧安装包与自动更新机制不代表当前版的安装或升级方式。

## 提示“已是最新版本”，为什么还要手动下载 r10？

R1 到 R10 使用相同的程序版本号 `0.1.0`，旧预览客户端无法通过这个编号区分修订。更新清单已补齐，官网也提供与 GitHub 原包一致的镜像，但它们没有改变旧客户端的判断方式。升级到 r10 请下载完整 ZIP、关闭旧版、解压到新文件夹并运行新启动器。当前更新流程不会自动替换或重启。

默认配置由同一 Windows 用户继续从原数据目录读取。若选择应用目录或自定义路径保存，需保留 `Data` 和 `.config_location` 位置标记，并核对原数据路径。完整步骤见 [升级与反馈](getting-started.md#升级与反馈)；确认设置和会话可见后再处理旧文件夹。

## 会上传我的对话吗？

**工具流分享默认开启，可在设置中关闭。** 最终选定方案后，分享可包含目标、完整方案、该会话的完整可见对话及执行结果。模型使用所需的输入与上下文则发送到你配置的模型服务。技能和跑分投稿需另外主动提交；关闭分享不会删除服务器已经收到的记录。完整说明见 [隐私说明](../PrivacyPolicy.txt)。

## 怎样提供有用的反馈？

向 [GitHub Issues](https://github.com/yujinchuan2021-max/zhenxing-ai-assistant/issues) 或 [枕星AI社区](https://community.zhenxingai.com/) 提交：版本与来源、系统版本、想完成的目标、最后一次操作、实际表现、期待结果及复现步骤。附脱敏截图；密码、API Key、授权链接和敏感会话不应公开。
