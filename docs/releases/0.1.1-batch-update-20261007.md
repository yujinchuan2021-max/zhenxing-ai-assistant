## 用户操作

1. 在应用中心刷新目录，查看「全部更新」旁的可更新数量。
2. 点击后确认工具清单、现有版本、目标版本和总下载大小。清单来自本机完整受管工具库存，搜索与状态筛选不会缩小更新范围。
3. 确认后，客户端从枕星下载服务逐项下载、校验并应用更新。任务卡显示当前工具、进度和每项结果；离开本页不会取消任务，返回后仍能查看。
4. 正在运行的工具保留现有版本，等待关闭后再重试。取消会停止尚未完成的下载，并撤销属于本批的等待请求；已经成功应用的更新保留。

只有已安装、由本应用管理、具有当前架构便携 ZIP 和有效入口的工具可以进入此批次。未下载的目录条目、本地登记软件、原厂 EXE 安装器、商店应用、账号登录和 USB 介质流程按各自方式处理。

## 下载与真实完成状态

确认时绑定工具的精确标识、版本和原包 SHA-256。开始应用时重新检查这些信息，目录目标发生变化会要求重新确认。支持相同版本号但包内容变更的修订。

下载校验、解压与文件切换沿用受管工具的现有事务保护。失败或取消保留原安装；某一项失败不阻止其他已确认项目继续。等待退出不算已更新，只有对应版本、包校验记录与有效入口均得到确认才计入成功。

云端目录刷新用于通知新版本，不会擅自更新全部工具。后台只重试用户已经确认的等待请求，并在同一事务锁内复核原请求，避免取消后重试重新建立它。
