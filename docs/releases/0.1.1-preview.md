## 本次变化

0.1.1 使用新的程序版本号和独立发布包。此前 R1 到 R10 的程序版本均为 `0.1.0`，无法依据版本号区分修订；更新清单发布后，旧 `0.1.0` 客户端可以检测到 `0.1.1` 并显示提示。

下载与校验后仍需手动关闭旧版，将完整 ZIP 解压到新文件夹，再运行根目录的 **「枕星图吧AI助手.exe」**。没有自动替换、自动解压或自动重启流程，不沿用历史 Electron 更新机制。

此前 r10 的社区授权会话修复、目标工作台、主题修复、技能库瀑布流和桌面 Agent 优先等能力保留。r10 的 [历史发布说明](r10.md) 和原始发布包继续保留，没有改写为 0.1.1。

## 保留配置与会话

升级前导出配置并备份实际数据目录。默认数据保存在 `%LOCALAPPDATA%\TubaWinUi3`，同一 Windows 用户的新版继续读取该位置。选择应用目录保存时，保留实际程序目录下的 `Data` 和 `.config_location` 标记，便携包中通常为 `src\Data`。自定义位置需要保留标记并核对原数据路径，相对路径还要保留目录结构。

自行添加的工具、第三方 Agent 配置也应单独保留。确认新版设置与会话可见后再处理旧文件夹；密钥绑定 Windows 用户，复制到另一用户或电脑不保证可以解密。历史 Electron 数据不会自动迁入 WinUI 3 数据目录。

本轮没有替换新版原生客户端实拍图。官网与 README 保留的客户端截图是此前界面示例，不能用来证明 0.1.1 当前 UI 已完成实拍验收。
