## 仍不能称为自有镜像的条目

Dism++ 的适用原样镜像授权仍需确认，不能删除协议“以非法的方式”的限定后断言所有镜像被全面禁止，也不能将翻译仓库的 MIT 套给程序。FanControl 应用采用专有的个人非商业许可，已去掉开源标签。这两项的当前原厂下载仍依赖 GitHub，未宣称国内直连完成。

[鲁大师桌面协议](https://www.ludashi.com/licence.html)允许非商业、完整真实原样分发，但商业分发、预装、捆绑需书面许可。已取得完整离线原 EXE、大小/SHA和有效签名，当前没有把这些事实当作本项目已有商业分发授权，因此继续提供完整原厂离线包入口。

MemTest86 Free 有作者管理员的镜像政策答复，但本机和自有服务器对两处官方原 ZIP 完整 GET 都返回 403，没有取得当前完整包、内含协议或整包 SHA；未绕过检查、使用来源不明转载包或冒充已上线。该条目保留真实官方启动 U 盘流程。

MSI Afterburner、RTSS、OCCT、UNIGINE、Maxon、Geekbench、Samsung Magician、AMD/NVIDIA Windows 软件及游戏加加存在具体分发限制或事先许可要求。HiBit、Geek、HDDScan、ThrottleStop、SeaTools、Intel XTU、360和卡巴斯基未确认到适用整包镜像授权，准确结论是缺少明确镜像证明，而不是断言作者全面禁止。逐项依据见[公开审核清单](../catalogs/tool-acquisition-audit.json)。

[六项许可询问草稿](../third-party-permission-requests.md)已准备，未发送、未联系作者。回函须覆盖实际运营、产品、原包、版本、未来更新及归属条件；没有回复不能当作许可。
