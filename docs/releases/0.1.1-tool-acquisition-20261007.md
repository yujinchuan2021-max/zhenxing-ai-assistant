镜像依据为作者管理员在[2019 年官方论坛的通用二进制再分发答复](https://forums.passmark.com/memtest86/44494-version-8-1-distribution-file-is-not-versioned)，并结合[2020 年针对 Free 镜像保持不过时的说明](https://forums.passmark.com/memtest86/49403-redistribution-of-memtest86-free-edition-via-linux-distro)及当前完整包内的协议核查。后者属于 Gentoo 场景答复，没有将它表述成本项目的单独书面授权。保留原作者、原包与协议，不转移 Pro/Site 许可证或密钥；后续新版本仍须重新取得完整原包、检查当期许可并验收后，以新哈希地址和更高目录修订发布。

它是 USB 启动介质包，不是受管便携 EXE 或 Windows 安装完成结果。原包包含 x86/x64/ARM64 EFI；实际使用要求 UEFI，传统 BIOS 和 Apple Silicon 不支持。解压需预留至少 1.1GB，用户自行备份 U 盘数据、选择目标设备并确认写入；下载或更新不会自动擦除 U 盘。此次没有运行 ImageUSB、写入 U 盘、重启或执行内存检测，也没有实测 Secure Boot 兼容性。

## 仍不能称为自有镜像的条目

Dism++ 的适用原样镜像授权仍需确认，不能删除协议“以非法的方式”的限定后断言所有镜像被全面禁止，也不能将翻译仓库的 MIT 套给程序。FanControl 应用采用专有的个人非商业许可，已去掉开源标签。这两项的当前原厂下载仍依赖 GitHub，未宣称国内直连完成。

[鲁大师桌面协议](https://www.ludashi.com/licence.html)允许非商业、完整真实原样分发，但商业分发、预装、捆绑需书面许可。已取得完整离线原 EXE、大小/SHA和有效签名，当前没有把这些事实当作本项目已有商业分发授权，因此继续提供完整原厂离线包入口。

MSI Afterburner、RTSS、OCCT、UNIGINE、Maxon、Geekbench、Samsung Magician、AMD/NVIDIA Windows 软件及游戏加加存在具体分发限制或事先许可要求。HiBit、Geek、HDDScan、ThrottleStop、SeaTools、Intel XTU、360和卡巴斯基未确认到适用整包镜像授权，准确结论是缺少明确镜像证明，而不是断言作者全面禁止。逐项依据见[公开审核清单](../catalogs/tool-acquisition-audit.json)。
