# 0.1.1 维护修订 — 2026-10-06 fix1

本次继续完善枕星图吧AI助手 **0.1.1**，程序版本保持 `0.1.1.0`，附件追加到现有 `v0.1.1-preview` 发行页。此前的源码标签和下载文件保留，当前维护源码使用 `v0.1.1-revision-20261006-fix1` 标签。

## 工具列表

- 便携客户端只查找自身 `Tools`，或带本产品启动器的便携包根目录 `Tools`，不再向盘符根目录或任意祖先目录寻找工具。之前解压到 D 盘时，可能误把已有 `D:\Tools` 的厂商安装目录当成分类，继而把 JRE、许可辅助程序当成工具卡片。本次不会移动或删除那些安装目录。
- 未安装的云目录条目必须有当前架构支持且元数据完整的便携下载包，或已声明的 HTTP(S) 官网入口；没有本地入口、下载包和官网的占位卡片隐藏。规则在显示时应用，因此已有云目录缓存同样适用，无需删除用户缓存。
- 已存在且可打开的本地入口继续保留。合法官网工具显示“网站 / 官网获取”，可下载安装的工具显示“待下载 / 下载”；显示下载按钮所用的包与当前架构一致。
- 声明主程序的工具在主程序缺失时，不再退回选择任意辅助 EXE。3DMark 和 DDU 补齐具体主入口声明。
- 目录变化时同时清理标签缓存，隐藏的空条目不继续贡献旧筛选标签。

## 配置修改器

编辑器并列显示 **原始名称、当前读到的 Windows 名称、目标展示名称**。保存本地目标不会把它当作已同步的 Windows 名称；系统或驱动重新生成名称后，刷新可以看到两者的差别。当前 Windows 名称是本次枚举的有效名称，不能代替对所有逻辑核心或第三方应用的验证。

顶部、设备编辑区、同步确认和结果区直接说明各类名称的作用范围，避免把“本地配置已保存”解释为全部软件都识别成了新硬件。同步和恢复后清理本客户端硬件摘要与详情缓存；失效前开始的盘点不再重新填回已失效缓存。重新打开硬件信息页会重新盘点，数据源仍可能返回真实型号。

| 类别 | 修改范围 | 查看效果时的限制 |
| --- | --- | --- |
| CPU | 单处理器系统的 Windows 名称显示字符串 | CPUID 读取仍可得到真实型号；多处理器或拓扑未知时仅本页保存。 |
| 主板 | Windows 主板名称和厂商显示字段 | 固件 SMBIOS 数据不变。 |
| 显卡 | 选中设备的 Windows 友好名称 | 驱动 / DXGI 报告的型号及显存不变。 |
| 显示器 | 选中设备的 Windows 友好名称 | EDID 中的型号、尺寸、分辨率不变。 |
| 硬盘 | 选中设备的 Windows 友好名称 | 控制器报告的产品标识、容量和序列号不变。 |
| 内存 | 本页本地配置和预览 | 不修改 SPD、SMBIOS 或实际容量、频率；没有 Windows 同步值。 |

第三方软件需要重新扫描才能核对修改后的显示结果；其旧扫描时间早于修改时，旧截图不能作为修改后验证。重新扫描也不保证该软件采用 Windows 名称字段。Windows 可从不同接口提供型号：[显卡 DXGI 描述](https://learn.microsoft.com/en-us/windows/win32/api/dxgi/ns-dxgi-dxgi_adapter_desc)、[存储设备产品描述](https://learn.microsoft.com/en-us/windows/win32/api/winioctl/ns-winioctl-storage_device_descriptor)。本工具不修改这些真实硬件描述。

## 下载与验证

下载文件名为 `ZhenxingAI-v0.1.1-preview-20261006-fix1.zip`，附同名 SHA-256 校验文件。关闭旧客户端后完整解压到新文件夹，运行根目录“枕星图吧AI助手.exe”。不要只替换单个 EXE。

当前维护修订保持相同数字版本，原有 0.1.1 的版本比较不会自动提示这次修订；官网更新清单本轮未修改。请按 GitHub 附件文件名和包内 `BUILD-INFO.json` 核对。个人数据、已有工具安装和硬件原值备份保留。
