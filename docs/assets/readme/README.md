# README 品牌素材

`brand-light.svg` 与 `brand-dark.svg` 是 1280 × 440 的自包含品牌横幅，用于仓库 README 的浅色与深色主题。四角星沿用本项目 `website-winui3/src/zxai/components/ZxStar.vue` 的原创路径。

横幅展示正式名称、产品定位、0.1.1 公开预览状态、Windows x64 与 WinUI 3，以及四步使用流程。流程明确标注为「使用流程示意」，不是客户端截图，也不代表安装、账号登录或作品制作已经完成。

SVG 不包含脚本、外部链接、远程字体、嵌入图片或 `foreignObject`。文字使用系统字体回退；正文与背景的对比度均不低于 4.5:1。素材随项目依据根目录 `LICENSE` 发布，不表示本项目具有上游认证或第三方认证。
