# 枕星图吧 AI 助手

面向 Windows 的 AI 助手与电脑工具工作台。说出要完成的事，助手协助澄清目标、比较方案、复用已安装的软件、准备工具，并给出下一步的打开方式。

当前公开版本为 **V0.1 · r10 预览版**，客户端采用 **WinUI 3 / .NET 10**。适合参与体验和反馈，仍在持续完善安装流程、界面和社区授权等环节。

[下载 Windows x64 便携包](https://github.com/yujinchuan2021-max/zhenxing-ai-assistant/releases/download/v0.1.0-preview-r10/ZhenxingAI-v0.1-workbench-preview-20261005-r10.zip) · [r10 更新说明](docs/releases/r10.md) · [官网](https://zhenxingai.com/) · [用户社区](https://community.zhenxingai.com/)

## 从这里开始

1. 下载便携 ZIP，**完整解压到一个新文件夹**。不要直接在压缩包内运行，也不要只复制启动文件。
2. 运行文件夹根目录的 **`枕星图吧AI助手.exe`**。部分系统与硬件功能需要管理员权限，启动时可能出现 Windows 授权提示。
3. 在“设置 → AI 与 Agent”配置模型接口和 Agent。个人 AI 相关功能复用这份全局配置；AI 服务的账号、网络可用性和费用由相应提供商决定。
4. 返回首页，输入目标，例如“我想在 Windows 做一款 2D 游戏”或“电脑卡顿，帮我排查”。根据选项选择方案，再确认需要的准备步骤。

已安装的工具应优先复用。可自动处理的安装步骤由客户端执行；账号登录、订阅及其他需要本人完成的步骤会单独提示。桌面软件和命令行工具的使用方式不同，任务工作台会提供对应的打开入口或启动说明。

没有配置 AI 接口，也可使用不依赖模型的本机工具、查看应用中心，以及阅读服务器已经更新的公开 AI 资讯。

## 可以做什么

| 入口 | 主要用途 |
| --- | --- |
| AI 助手与任务工作台 | 以目标组织对话、方案和准备进度，提供下一步操作与工具入口。 |
| 应用中心 | 查看本机软件、应用管理记录和下载任务，提供可用的打开、位置、快捷方式及卸载入口。 |
| 电脑工具与硬件信息 | 查看硬件、进行诊断和性能测试，使用内置工具或按需获取第三方软件。 |
| 官方技能库 | 搜索和分类浏览技能；支持本机技能导入、修改、制作与试用，主动提交的修订进入审核流程。 |
| 枕星 AI 资讯 | 阅读来源明确的资讯与原文；客户端可使用个人 AI 配置进行额外整理。 |
| 枕星 AI 社区 | 在内置浏览器里交流目标、工具使用经验和问题反馈。 |

云端服务、工具包来源和第三方账号都独立于客户端。**有客户端入口不代表所有服务、第三方安装包或授权方式都已完成公开验收。** 例如，本次 r10 的社区授权测试使用隔离的模拟页面，没有替用户完成真实账号注册或登录。

## r10 的主要变化

本轮重点修复社区注册、登录过程中出现的“授权超时或您已切换浏览器”：社区身份服务的授权在同一个内置浏览器会话里继续，保留原始表单提交；遇到需要外部浏览器完成的登录方式，提供从社区登录首页重新开始的明确入口。

浏览器中的登录只对该浏览器生效，不会自动把客户端登录。失败、超时、离开页面和重试都有对应处理。此前的社区标题去重、主题修复、技能库和桌面版优先等改动保留。

验证范围、已知限制和下载校验值见 [r10 更新说明](docs/releases/r10.md)。

## 数据与隐私

应用以本机功能为主，联网功能包括你配置的模型请求、搜索、下载、资讯、社区及主动上传等。**工具流分享默认开启**：选定方案后，可向枕星服务器发送项目目标、完整方案、该会话的完整可见对话，以及相关执行结果和汇总计数；可以在设置中关闭。技能投稿和跑分上传需要另行主动提交。

API Key 使用 Windows 当前用户的数据保护机制保存在本机。请不要把 Key、令牌或未脱敏的会话与日志放进公开反馈。更多细节见 [隐私说明](PrivacyPolicy.txt)。
