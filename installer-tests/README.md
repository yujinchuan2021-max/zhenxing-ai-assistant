# 安装器隔离验证

这些脚本用于检查仓库中的四份 `installer*.iss`。路径规划测试使用构造的字符串和内存文件系统模型；编译测试使用临时桩载荷。它们不执行真实安装或卸载，不能代替隔离虚拟机里的升级、保留数据及卸载验收。

## 运行

在 Windows 上从仓库根目录执行：

```powershell
$env:TUBA_REPO = (Get-Location).Path
python .\installer-tests\uninstall_path_planning_test.py
python .\installer-tests\compile_check.py
python .\installer-tests\compile_check.py --negative
```

`uninstall_path_planning_test.py` 读取安装脚本，检查删除边界、路径规范化、重解析点和卸载日志身份规则，不操作真实目录。脚本返回值和实际输出才是本次验证结果。

`compile_check.py` 需要 Inno Setup 的控制台编译器 `ISCC.exe`。脚本依次检查显式的 `TUBA_ISCC`、PATH 和常见安装位置；可自行将 `TUBA_ISCC` 设置为合法取得的控制台编译器路径。找不到编译器时退出，不回退到 GUI 编译器。PE 类型检查也会拒绝 GUI 可执行文件。

编译脚本将源文件替换为少量文本桩载荷，在本次随机临时目录内生成安装器，**只编译，不安装**。默认清理该临时目录；`--keep` 可保留供人工检查。`--negative` 显式加入语法错误负控，要求编译器返回失败、给出预期错误定位且没有负控安装器残留。

## 覆盖范围与限制

- 任意自定义数据目录不能凭名称、标记文件或通用文件名单证明归属，测试检查其保留行为。
- 从盘符根或共享根到删除目标的整条路径都需要检查重解析点；无法确认时拒绝删除。
- 卸载日志需要匹配应用身份和安装模式；多个日志或无法识别的格式应触发保守处理。
- 日志头部识别依赖 Inno Setup 的实现细节，工具版本改变后应重新核对。
- 真实安装器、旧版本迁移、管理员授权和用户数据保留仍需在专用虚拟机或快照中验收。

公开源码没有附带维护者机器上的历史日志或编译器。请记录自己实际使用的工具版本、来源、校验值和验证结果；本次 r10 社区测试并不表示这些安装器测试也已重新执行。一般构建说明见 [源码构建文档](../docs/build.md)。
